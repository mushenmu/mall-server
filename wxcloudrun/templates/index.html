🛍️ 木神木简单商城 API

微信云托管 Django 后端 · 配套小程序:mushenmu-mall-mini

首页 / 分类 / 商品

方法路径说明
GET/api/home轮播图 + 分类宫格 + 热门商品
GET/api/category/list分类树(两级)
GET/api/goods/list商品列表/搜索(keyword/categoryId/pageNum/pageSize/sort)
GET/api/goods/detail?id=商品详情
GET/api/search/popular热门搜索词

用户 / 地址

方法路径说明
POST/api/user/login微信登录(code 换 uid)
GET/api/user/center?uid=用户中心 + 订单统计
GET/api/address/list?uid=地址列表
POST/api/address/save新增/编辑地址
POST/api/address/delete删除地址

购物车

方法路径说明
GET/api/cart?uid=购物车列表
POST/api/cart/add加入购物车
POST/api/cart/update更新数量/选中
POST/api/cart/delete删除条目

订单

方法路径说明
POST/api/order/commit提交订单
GET/api/order/list?uid=&status=订单列表
GET/api/order/detail?orderNo=订单详情
POST/api/order/pay模拟支付
POST/api/order/cancel取消订单
POST/api/order/confirm确认收货
说明:统一响应信封 {data, code, msg, success};价格单位为「分」(整数), 前端展示时除以 100。未配置 WX_APPID/WX_SECRET 时登录走开发模式 (任意 code 映射同一 mock 用户),本地联调无需真实密钥。
